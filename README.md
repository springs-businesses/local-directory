# Springs Local Small Businesses

A free Colorado Springs directory that helps residents find vetted local small businesses by the exact service they need.

## Planned Features

- Search approved local businesses by service category
- Search for exact services through All Other Services
- Free customer accounts
- Saved customer searches
- Free business listing applications with admin review before approval
- Donation option to help cover maintenance and upkeep

## Main Service Categories

- Handyman Services
- Cleaning Services
- Junk Removal Services
- Moving Services
- Auto Services
- Tech Services
- Pet Services
- Catering & Event Services
- Lawn Services
- Tree Services
- Fence Services
- Plumbing Services

## Status

This project is currently being built from scratch.
